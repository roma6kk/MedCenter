## Открытые вопросы для владельца

1. **Поиск пациента врача.** На стороне врача нет эндпоинта поиска пациентов (patient-service отдаёт карточку только по id и только при наличии лечебной связи). Поиск работает по пациентам собственного журнала врача за последние 90 дней и ближайшие 30 (один запрос, страница 100; нужны ≥ 2 символа; пациенты только с отменёнными/неявочными записями не предлагаются, потому что их карточка ответит 403). Пациент без записей в этом окне не найдётся; при > 100 записях за 4 месяца найдутся не все. Нужен ли настоящий эндпоинт `GET /patients?search=` с проверкой связи — решение за вами (это бэкенд).
2. **Загрузка в админке.** Реальную загрузку (занято/свободно по дням для врача или кабинета) дёшево получить нельзя: слоты читаются по одному расписанию, одной страницей ровно в 20 (`SLOT_PAGE_LIMIT`), так что на неделю по всем врачам понадобились бы десятки запросов с неполным ответом. Вместо этого сделан недельный план рабочих окон. Если загрузка нужна, потребуется агрегирующий эндпоинт (например, `GET /admin/schedules/load?from=&to=` со счётчиками free/busy по расписанию и дню).
3. **Имя пациента в слоте.** Слот расписания пациента не содержит; имя подтягивается из журнала той же недели по `slotId`. Это работает, пока в неделе ≤ 100 записей (иначе показывается предупреждение «Показаны не все записи недели»). Если нужно без этого ограничения — добавить `patientId/appointmentId` в ответ `GET /doctor/schedule`.
4. **Шторка бургера открывается справа.** Переиспользован `Dialog` варианта `drawer` (он по дизайну справа), а бургер стоит слева. Если нужна шторка слева, добавьте вариант в `Dialog` (одна ветка классов и ключевой кадр).
5. **Меню профиля вместо отдельного `DropdownMenu` из «⋯».** В `DropdownMenu` добавлены кастомная кнопка, `menuitemradio` и заголовки групп; так сохранена WAI-ARIA-модель меню, но примитив стал чуть шире. Если предпочтительнее отдельный компонент «меню профиля» — скажите.
6. **Карточки таблиц на телефоне (D7 про «имя + роль чипом + ⋯»)** не менялись: `MobileCards` по-прежнему печатает «Колонка: значение» в каждой строке. Менять их можно только вместе со всеми таблицами админки (отдельная задача).
7. **Контраст `--glass`.** Токен прозрачный, пара «текст на стекле» не вошла в `globals-contrast.spec.ts` (итоговый цвет зависит от фона под ним). Текст стоит на почти белом (светлая тема) или почти фоновом (тёмная) результате; при необходимости добавлю проверку на составной цвет.
