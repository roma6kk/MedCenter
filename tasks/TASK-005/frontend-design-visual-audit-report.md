## 2. Что есть сейчас (по коду)

- Tailwind **3.4**, токены — hex в `:root` (`globals.css`), палитра из одного бирюзового акцента `#0f766e` + серо-зелёные нейтральные.
- Шрифты: Onest (текст и заголовки) + JetBrains Mono — моно используется в **30 файлах** (время, даты, коды, бейджи длительности).
- Размеры шрифта: помимо `text-xs…2xl` — **11 произвольных** значений (`text-[13px]`, `[15px]`, `[17px]`, `[19px]`, `[22px]`, `[28px]`, `[30px]`, `[32px]`, `[34px]`…) — шкалы нет.
- Скругления: 4 токена (`6/10/16/20 px`) + разрозненные `rounded`, `rounded-md`, `rounded-sm`, `rounded-full`.
- Тени: всего **6** использований на весь проект — интерфейс почти плоский, глубина передаётся только рамкой `#dce4e5`.
- Движение: `transition-colors` ×6, `animate-pulse` ×4 (скелетоны). Hover кнопок — `opacity-90`. Других анимаций нет.
- Тёмная тема описана (`[data-theme='dark']`), но переключателя нет и к `prefers-color-scheme` она не привязана — недостижима.
- UI-примитивов три: `button`, `card`, `avatar`. Поля, select, бейджи, диалоги, табы, тосты, таблицы собираются по месту.

## 3. Реестр визуальных проблем

Важность: **H** — портит впечатление на ключевых экранах; **M** — заметная несогласованность; **L** — полировка.

### V-A. Цвет

| # | Важн. | Проблема | Предложение |
|---|---|---|---|
| VA1 | **H** | Монохромный интерфейс: один бирюзовый акцент на светло-сером фоне, всё остальное — серые рамки. V1 — до всего остального: остальные задачи опираются на токены. V2 совмещать с T2 из UX-аудита (паттерн разрушительных действий и тосты).

**Решение по Tailwind (владелец, 2026-10-26): обновлять только при необходимости — необходимости нет, остаёмся на 3.4.** Всё из плана работает на v3 без обновления:
- OKLCH-цвета, `clamp()`-шкалы, тени и моушн-токены — обычные CSS-переменные в `:root`, подключаются через `theme.extend` (так уже сделаны текущие цвета и радиусы);
- прозрачность для цветов из переменных — `color-mix(in oklch, var(--x) 20%, transparent)` или канал-переменные;
- View Transitions, scroll-driven анимации, `text-wrap: balance`, `tabular-nums` — нативный CSS, от версии Tailwind не зависят;
- `@theme`, OKLCH-палитра по умолчанию и CSS-first конфиг v4 — удобство, а не возможность, которой нет в v3.

Пересмотреть, если появится зависимость, требующая v4 (например, библиотека компонентов, собранная только под v4).

## 5. Состояние стека

Во время обхода данные не менялись: диалог отмены записи и форма нового пользователя открывались и закрывались без отправки.
